## 会检查我的存档吗？

会。Mod在游戏运行时查询**你当前载入存档**的游戏事实和昆特卡组，不读取作者的扫描报告，不联网，不上传存档。
- 原游戏已记下首胜的商人，安装后自动识别并隐藏其对战标记。
- 没有首胜记录不等于从未对战：输过、弃局、随机奖池耗尽后的旧胜利，以及个别NPC，可能没有可恢复的记录。
- 任务对手按其卡牌是否已获得判断；这不保证证明你亲自打赢了该NPC。
- B在打开商店和成功交易更新商人信息时，清点**实际商店库存**中的昆特牌数量，包括同种牌的多张副本。尚有牌继续提示，核实为0则隐藏购牌提醒。
- B把核验结果作为 `gwm_shop_seen_*` / `gwm_shop_left_*` 辅助事实，随你正常保存游戏而保存。离开商人、卸载区域后不再因为库存读不到而重新出现。切换到别的存档时读取另一个存档的事实，不共用购买进度。
- 安装前的所有购买历史不能完整反推；未核验的商人保留“待核实”。打开该商店后才能核实，不会因卡组里已有同名卡就认定买齐。已记录的是最近一次实际商店核验，其他Mod改变库存后应重新打开商店更新。

## 安装（Windows）

1. 从 Releases 下载 **A或B的ZIP**，不要把仓库的 Source code ZIP 当作安装包。完整解压到新文件夹。
2. 备份自己的存档，完全退出游戏。双击 `Install.cmd`，输入游戏目录（里面应有 `bin` 和 `content`）。安装器不包含任何作者电脑路径。
3. 游戏设置中启用 Mods / 本地Mod，启动并等待脚本编译，然后载入你自己的存档。
4. 打开大地图，切换“昆特牌”或“全部”筛选。已首胜的对战标记隐藏；【购牌】图标独立显示。
5. 手动安装：把包内 `release` 的内容复制到游戏目录，确保脚本位于 `mods/modGwentPlayersMap/content/scripts/local/gwm.ws`。手动安装没有卸载回执。

安装器检测所需脚本接口，校验包内SHA256，拒绝覆盖现有同名文件，不改原版脚本、`input.settings` 或磁盘存档。换版本先用原包 `Uninstall.cmd` 卸载。直接覆盖时务必确认没有遗留脚本；不要同时装本分支与原作者同名模块。

## B的小地图怎么显示？

旧版只接入大地图，未向HUD注册标记，所以小地图原本不会显示。B增加附近已加载NPC的原生动态标记，约每秒更新：
- 原生 **User1** 自定义标记：尚未检测到首胜。
- 原生 **User2** 自定义标记：已首胜，但还有牌可买或购买状态待核实。
- 同一商人只显示一个提醒，优先对战；首胜后还有购牌事项则切换到购牌提醒，两项都完成则隐藏。
- 只处理当前区域约150米内、已加载且能识别的商人。受原生小地图缩放/范围和NPC作息影响；不是全地图远距离雷达。
- 不修改小地图SWF，因此这里使用原生标记，**不是大地图的卡牌贴图**；不占用手工图钉槽。原版商店图标不会被本Mod删除。
- 部分无已知NPC标签的任务旅店老板，要在该存档实际打开商店后才能关联；未识别NPC不猜测标记。

## 兼容性与当前限制

本分支按重制版5.01时期的本机脚本接口制作（内部构建5.0.0.1048522），不能保证其他补丁、平台或昆特大改兼容。安装器接口检查通过也**不等于已通过游戏编译**。主机/跨平台mod.io安装不支持此Windows ZIP。

固定对手列表约91点，不保证覆盖所有可对战NPC或所有仅卖牌的商人。商人按作息/任务出现。修改 `panel_worldmap.redswf` 的其他地图Mod需要对应合并文件；只会加载一份地图资源。

B新增的HUD/交易钩子尚未经过本分支实际游戏编译和画面验收。已有离线状态、跨存档隔离、安装/卸载、补丁和回滚检查，不能把这些说成游戏里已成功显示。出现脚本错误请保留完整报错，退出游戏后卸载本Mod，并在 Issues 提交版本、其他Mod列表和截图，**不要公开上传私人存档或凭据**。

## 卸载

退出游戏，双击安装时保留的 `Uninstall.cmd`。只删除与安装回执哈希一致的Mod文件；手动改过的文件会拒绝删除。手动安装者仅移除本Mod文件夹和本Mod菜单XML。

卸载不会退回已正常保存的游戏进度，也不会替你删除存档中的辅助事实。需要撤销游戏进度时，读取事先备份的存档。
